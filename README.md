# SanVIST 运营后台原型

独立的运营后台原型，包含社区管理和 PC 快速链接配置。

## 本地运行

```bash
npm install
npm run dev
```

默认本地地址为 `http://127.0.0.1:5175/`。

## 发布地址

`https://huajie-git.github.io/SANY/admin/`

本项目使用 `admin` 分支发布到 GitHub Pages 的 `admin` 子目录。

## PC 快速链接配置原型

入口：`/#/quick-links`。列表支持查询、三类链接筛选、启停、编辑和确认删除。

新增/编辑在一个连续表单完成，全部 14 种可选语言同时展开：

- 链接类型：内部链接、网页（Web/H5）、网页（Web/H5，需鉴权）；均填写访问地址。内部不选择功能模块，可填写完整网址、站点路径或 `#/` 路由。
- 基础配置上方集中设置默认显示、NEW 角标和仅 Pro 用户；Pro 仍与用户范围、角色及产品组取交集。
- 所有用户/企业用户/指定用户单选；企业与产品组同页多选，清空不限制；角色单选，旧多角色保持兼容。
- 多语言名称缺失回退默认英文，语言图标缺失回退通用图标；格式 PNG/JPG/WebP，非空且不超过 150KB。保存失败与并发保留输入，取消需确认放弃。
- 平台免登录与接入系统功能已删除。“需鉴权”由目标网页处理身份校验，不在平台生成、拼接凭证；PC 直接按链接访问，无免登录弹窗。
- 不提供工作台预览、样例验证、规则摘要或演示页面；保留必要的输入错误与指定用户冲突反馈。

同源本地联动：PC 运行 `SANVIST_PREVIEW_SHARED_ORIGIN=1 npm run dev`，Admin 运行 `npm run dev`，打开 `http://127.0.0.1:5175/#/quick-links` 与 `http://127.0.0.1:5175/pc/#/workbench`。原型使用本地存储与样例目录，不代表真实配置服务已接通；保留用户个人显隐与排序。
