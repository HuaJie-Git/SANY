# SanVIST 运营后台原型

独立的运营后台原型，包含社区管理和 PC 快速链接配置。

## 本地运行

```bash
npm install
npm run dev
```

默认本地地址为 `http://127.0.0.1:5175/`。

## 发布地址

`https://huajie-git.github.io/SANY/admin/`

本项目使用 `admin` 分支发布到 GitHub Pages 的 `admin` 子目录。

## PC 快速链接配置原型

入口：`/#/quick-links`，对应左侧「配置管理 → PC 快速链接」。原有四项是初始入口；可新增自定义链接，并配置名称、访问地址、排序、启停、可见范围及本地上传图标（PNG/JPG/WebP，最大 150KB）。未上传时显示默认图标；可更换图片或恢复默认图标。可见范围为「所有用户」「企业用户」「指定用户」：企业用户须选择一个企业租户，该租户下的用户可见；指定用户通过搜索和多选确定。

| 前置条件 | 操作与结果 | 异常提示与恢复 | 输入保留 / 记录 |
| --- | --- | --- | --- |
| 首次进入，尚无配置 | 展示四个系统预置入口；可点「新增」创建新入口 | 新增弹窗取消后列表不变 | 未保存不产生配置记录 |
| 新增或编辑 | 校验名称、地址、排序、可见范围、图标后保存；开启且命中可见范围的链接显示在 PC | 重名、空名称、非法 URL、超长或无效图片在弹窗内提示 | 校验失败保留输入；保存成功更新修订号 |
| 新增未选可见范围，或指定用户未选人 | 不保存配置 | 在对应区域提示选择范围或至少一位用户 | 保留其他输入；选择后可重试；不产生配置记录 |
| 企业用户未选租户，或原租户已失效 | 不保存配置 | 提示选择有效的企业租户 | 保留其他输入；重新选择后可重试 |
| 指定用户搜索无结果、原用户已失效 | 搜索无结果显示空状态；失效用户不能提交 | 提示换关键词或移除失效用户重新选择 | 保留已选的有效用户与其他输入 |
| 关闭或删除 | 关闭后 PC 不展示；自定义项删除前二次确认 | 取消删除保持原状；系统预置项不可删除 | 成功后更新浏览器配置 |
| 保存失败或配置已被其他页面更新 | 不覆盖新版本 | 保留弹窗与输入，提示刷新列表或重试 | 不产生新记录 |
| PC 地址不可用、用户不在可见范围或本地配置被删除 | 自定义无效地址不展示；未命中范围的用户不展示；系统预置项空地址沿用内部页面 | 运营可重新编辑或开启；PC 原型可切换身份验证结果 | 不自动覆盖原配置 |

[假设] 原有四项兼容旧配置，未设置范围时按「所有用户」展示；系统预置项允许修改与关闭，但不可删除；新增项必须填写 `http/https` 地址，并在新标签页打开。上传图标暂支持 PNG/JPG/WebP、最大 150KB，可更换或恢复默认图标。当前原型用样例账号和租户模拟可见范围，未增加设备条件；正式上线所需的服务端身份校验、配置存储、权限、操作审计、跨浏览器同步及图标文件规格均待确认。

本地联动预览：在 PC 项目运行 `SANVIST_PREVIEW_SHARED_ORIGIN=1 npm run dev`，在本项目运行 `npm run dev`，然后分别打开 `http://127.0.0.1:5175/#/quick-links` 与 `http://127.0.0.1:5175/pc/`。两个页面同源，可立即看到新增链接在 PC 首页生效。
